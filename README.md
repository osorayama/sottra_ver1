# Sottra

旅のルートを記録して、写真付きで共有できる旅SNSアプリです。

## 主な機能

- ログイン / 新規登録
- 写真付き投稿
- GPSルート記録
- 地図で投稿・ルート表示
- 場所検索
- 近くの旅人表示
- 旅友達フォロー
- コメント / 「行きたい！」
- チャット

## 技術

- React + Vite
- Firebase Authentication
- Firestore
- Firebase Storage
- Firebase Hosting
- MapLibre GL JS

## こだわり

- 旅の記録を、あとから見返したくなるように「写真」だけでなく「移動ルート」も残せるようにした
- 地図はできるだけ気軽に使えるよう、APIキー不要で扱いやすい構成にした
- モバイルでの使いやすさを優先して、片手でも触りやすいUIを意識した
- 近くの旅人や旅友達の仕組みを入れて、旅先で人とつながれる体験を目指した
- 投稿への反応は、単なる「いいね」ではなく、旅らしく「行きたい！」という気持ちで表現できるようにした
